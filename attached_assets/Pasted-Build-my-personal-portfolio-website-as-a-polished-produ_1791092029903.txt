6. FLOATING OBJECT PHYSICS
==================================================

The 3D objects should have subtle motion.

Use different motion patterns:

Object A:
slow vertical float

Object B:
slight rotation

Object C:
slow orbit/parallax

Object D:
small mouse-following movement

Object E:
very subtle oscillation

Motion should be slow and premium.

Example:
5–12 second animation cycles.

DO NOT make them bounce aggressively.

DO NOT make them spin continuously like loading icons.

On mouse movement:
objects should shift approximately 5–20px depending on depth.

Use spring-like motion.

On hover:
- object slightly enlarges
- rotation responds to cursor
- label appears
- subtle shadow changes
- nearby technical annotation can activate
